# 使用说明

## 1. 准备

1. 安装并启动 PC 学习通客户端 `cxstudy.exe`。
2. 在客户端里登录，并至少打开一次课程。
3. 程序会读取客户端本地已登录的 Cookie，不会保存账号密码。

## 2. 安装

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

或者直接运行 `run.ps1`（会自动创建虚拟环境并安装依赖）。

## 3. 检查环境

```powershell
python -m chaoxing_flow doctor
```

看到 `登录校验: OK` 和课程列表即可。

## 4. 常用命令

```powershell
python -m chaoxing_flow courses
python -m chaoxing_flow chapters --course "课程名"
python -m chaoxing_flow materials --course "课程名" --chapter "1.1"
python -m chaoxing_flow questions --course "课程名" --chapter "1.1"
python -m chaoxing_flow solve --course "课程名" --chapter "1.1"
```

`solve` 默认只预览答案，不写入平台。

确认后加 `--save`：

```powershell
python -m chaoxing_flow solve --course "课程名" --chapter "1.1" --save --verify
```

`--save` 默认会完成本章的文档类任务点（PDF/PPT/Word 等），然后调用“暂时保存”。

- 只想暂存、不处理任务点：加 `--no-complete-jobs`
- 只完成任务点、不暂存：加 `--complete-jobs`，不要加 `--save`
- 作业任务点需要提交/批阅；视频/音频任务点需要播放，均不会自动完成

## 5. 大模型配置

复制 `config.example.env` 为 `.env`，填入：

```ini
CX_LLM_API_KEY=你的 key
CX_LLM_BASE_URL=https://api.openai.com/v1
CX_LLM_MODEL=gpt-4o-mini
```

然后在 `solve` 后加 `--llm`。系统环境变量优先于 `.env`。

`.env` 已被 `.gitignore` 忽略，不要提交到公开仓库。

## 6. 打包 exe

```powershell
.\build_exe.ps1
```

生成 `dist\chaoxing-flow.exe`。把 `answer_banks`、`config.example.env` 放在 exe 同目录即可使用；需要大模型时，把 `.env` 放在 exe 同目录。

## 注意

- 本工具没有“提交作业”功能，只调用“暂时保存”。
- 请先预览、核对答案，再决定是否暂存。
- 仅用于 Windows，且需要能访问学习通域名。
- 请遵守学校和课程的使用规定，风险自负。
